The download is one file, jasiri-sideload.apk, version 0.21.0, about 55 MB. These checks compare that file with the facts on this page. They do not send the file to Jasiri. This page sets no cookies and runs no analytics. The privacy page says how the site is hosted.

File hash

The SHA-256 of this download is:

06a15a05be8d0dfb61e7e8118073866e5f539439a77894ae6db9c1b4d3a5a6e2

Compute the hash of the file you downloaded. The two strings should match, letter for letter.

$ sha256sum jasiri-sideload.apk

On Windows, in PowerShell:

PS> Get-FileHash jasiri-sideload.apk -Algorithm SHA256

The release notes are on the latest release. PowerShell prints the hash in capitals. Lowercase is the same value.

Signing certificate

The file is signed. This fingerprint is the signing certificate, and it stays the same from one version to the next. It is not a secret. A file can have the right name and the wrong signature. If the hash matches the one above and this fingerprint matches too, the file is the one that was published.

If Java is installed:

$ keytool -printcert -jarfile jasiri-sideload.apk

Look for the SHA256 line under the certificate fingerprints. With the Android SDK, apksigner verify --print-certs jasiri-sideload.apk prints the same line.
