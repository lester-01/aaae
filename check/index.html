Check the APK

Last updated 17 October 2026

The download is one file, jasiri-sideload.apk. These checks compare that file with the published release. They do not send the file to Jasiri. This page sets no cookies and runs no analytics. The privacy page says how the site is hosted.

File hash

Each release lists a SHA-256 checksum for the file. The same value is sideload.sha256 in policy.json, which is the small file installed copies of Jasiri read when they look for an update. Compute the hash of the file you downloaded and compare. The two strings should match, letter for letter.

$ sha256sum jasiri-sideload.apk

On Windows, in PowerShell:

PS> Get-FileHash jasiri-sideload.apk -Algorithm SHA256

The release notes are on the latest release. PowerShell prints the hash in capitals. Lowercase is the same value.

Signing certificate

The file is signed. This fingerprint is the signing certificate, and it stays the same from one version to the next. It is not a secret. A file can have the right name and the wrong signature. If the hash matches the release and this fingerprint matches too, the file is the one that was published.

SHA-256:

80db1f0580c90d3bb7ec1d06ef1daa9810e8e8e0bdab80ebde9a2ae7e1823202

The same fingerprint, with colons, which is how the tools below print it:

80:DB:1F:05:80:C9:0D:3B:B7:EC:1D:06:EF:1D:AA:98:10:E8:E8:E0:BD:AB:80:EB:DE:9A:2A:E7:E1:82:32:02

If Java is installed:

$ keytool -printcert -jarfile jasiri-sideload.apk

Look for the SHA256 line under the certificate fingerprints. With the Android SDK, apksigner verify --print-certs jasiri-sideload.apk prints the same line.

Upload the APK

The download is about 57 MB. That page can warn that a small upload stops at a few megabytes, and then accept the file anyway. A file this size uses VirusTotal’s large upload, which accepts up to 650 MB. That large upload is not a second page. It is the way a file over 32 MB is sent, including from the upload page above.
