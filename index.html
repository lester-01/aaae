Ask. Watch it work. Or do it yourself.

The pocket computer includes a Linux system. That is where programs and files live. The terminal is the text screen for that system. You can leave it closed.

The AI assistant is built into the Linux system on the phone. It uses the same files and the same programs as the terminal.

  1. Ask

    Say what you want in a chat. A chat is one conversation. Attach a photo or a document when it helps.

  2. Watch it work

    The AI assistant writes files, runs them, and installs a program when the task needs one. You can see each step.

  3. Do it yourself

    Open the terminal when you want the same Linux system, and the same files, under your own hands.

The terminal is there when you want it

Type jasiri for a short guide, including the line that reaches this phone from a laptop. Installing a program from here is the same Linux system the AI assistant uses.

What you can do today

These are in the current app. Each chat keeps its files in a folder. Delete the chat, and that folder goes with it.

  • Build something from a sentence

    Describe a page, a script, or a small tool. The AI assistant writes it, runs it, and shows you the result.

  • Turn a photo into data

    Attach a receipt, a form, or a whiteboard. Ask for a spreadsheet or tidy notes. This needs a model that can see images. The file still saves if the model cannot.

  • Learn on the Linux system

    Practice Linux, Git, Python, or the shell from the AI assistant, or from the terminal, on a real system in your pocket.

  • Use the clipboard

    The AI assistant can read what you copied. That starts on. Putting text back on the clipboard starts off, until you allow it.

  • Reach it from a laptop

    Install the SSH server, and the same system is one command away from a computer on your network.

  • Save a task for later

    An automation is a saved task that runs on a schedule. You set it up yourself. A skill is the instructions the AI assistant follows for one kind of task. Both ship with Jasiri.

What is coming

A package manager

A package manager is a page where you search for a program and press Install. Desktop computers have had this kind of page for years. You will be able to add software without opening the terminal. That page is not in Jasiri yet.

Until then, you and the AI assistant share the Linux system. The AI assistant can install a program when a task needs it. You can install from the terminal.

Plugins

A plugin is an extra that adds a trick. The plans include searching your photos by describing them, shrinking a video, keeping notes, and backing up on a schedule. Every one of those is coming soon. None of them is in the app yet.

What you can do now is smaller, and it is real. You can attach one photo in a chat when the model can see images. Each chat already has a folder. You can copy that folder out yourself. A backup that runs on a schedule is still to come.

What stays off until you allow it

Jasiri starts with what a basic chat and the Linux system need. Photos, the microphone, notifications, and other reaches into the phone stay off until you allow them.

On the full edition, control of other apps is one of those reaches. It stays off until you allow it. Leave these off if chat is enough.

Two editions

Both editions have the pocket computer, the terminal, the AI assistant, a browser inside the app, skills, and automations.

This website offers the full edition. It also has tools a Play edition will not be allowed to include. Those tools can control other apps on the screen, see and open every app you have installed, and install an app file, including an update to Jasiri. When Play is the place you got Jasiri, Play is also the place that updates it.

Choose this website if you want those tools. The Play edition is enough if you want the AI assistant, the terminal, and the Linux system. Play is not listed yet. The download on this page is the full edition.

The two editions share one identity on the phone. You cannot keep both installed. Moving from one to the other later means installing again.

Questions

Is it free?

The core is free to install and use, including for work. Convenience tools may cost money later. Support is not included.

Do I need an AI API key?

Yes. You bring an AI API key from OpenRouter, OpenAI, or another compatible service. Jasiri does not sell the model. That service may charge you, and you choose the model.

Which phones does it run on?

Android 8 or later, on a 64-bit phone. Jasiri does not need a rooted phone. A recent phone is more comfortable for a longer job.

Is it on Google Play?

Play is not listed yet. This site has the full edition. When Play lists Jasiri, that edition will leave out some tools for controlling other apps, seeing every installed app, and installing an app file. The editions section says which one to choose.

Does it work offline?

The Linux system and your files work without a connection. The AI assistant needs to reach the provider you chose. Running a model on the phone itself is a plugin, and it is coming soon.

What can the AI assistant touch?

It starts with the chat and the Linux system, including each chat’s folder. Photos, the microphone, notifications, and other reaches into the phone stay off until you allow them. On the full edition, controlling other apps is one of those, and it stays off until you allow it. The AI assistant can read the clipboard from the start. Writing to the clipboard starts off.

Where does my data go?

Your messages and any attachments go to the provider you picked, under that provider’s terms. Jasiri has no account and no analytics. The privacy page has the rest.

Can I ask for a plugin?

Yes. Email contact@benlester.me and describe the trick you want.
