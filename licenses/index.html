The Linux system

Jasiri ships a Linux user space built from the Termux packages project, plus packages you install later from its package servers. It contains many programs, among them the GNU core utilities, Bash, the Debian package tools (apt and dpkg), and others. Each program is distributed under its own license, many of them GPL or LGPL. Jasiri runs these as separate programs on your phone and does not combine them with its own code. For the build of the Linux system that Jasiri ships, we adjust file paths inside some binaries so they work in Jasiri’s own storage location. These are modifications under those licenses.

Full license texts for these programs are in the Linux system itself, under usr/share/doc and usr/share/licenses. The corresponding source code is published by the Termux packages project at github.com/termux/termux-packages. If you would like a copy of the source for any program in Jasiri under its license, email contact@benlester.me and we will provide it.
