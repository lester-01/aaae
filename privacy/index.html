Privacy

Last updated 19 October 2026

The short version: Jasiri has no account, no ads, and no analytics. Your chat folders stay on your phone. The messages you send the AI assistant go to the AI provider you choose, and nowhere else.

What stays on your phone

  • The Linux system, your chat folders, and everything the AI assistant writes. A chat folder is where that conversation’s files live.
  • Your AI API key, and any SSH keys you create. Jasiri opts out of Android backups, so those keys are not copied to the cloud by that backup.
  • Uninstalling Jasiri removes all of it.

What goes to your AI provider

When you ask the AI assistant for something, Jasiri sends your message, any attachments, and the output of commands the AI assistant runs to the service you configured. That can be OpenRouter, OpenAI, or another compatible service, using the AI API key you pasted. That provider handles it under its own terms and privacy policy. Choose a provider you trust. Ben Lester does not operate that service and does not receive a copy.

What Jasiri collects

Nothing about you. There are no accounts, no advertising identifiers, no analytics, and no crash reporting in the current version.

Network requests Jasiri makes

  • Update check. When you open the app, it reads a small public file on this website to learn the latest version. The file is the same for everyone. Like any web request, your IP address is visible to the host (GitHub Pages and Cloudflare) in their ordinary logs.
  • Your AI provider, as described above.
  • Package downloads. When you or the AI assistant install software, Jasiri downloads packages over HTTPS from the package servers for its Linux system.
  • Anything you or the AI assistant run. The terminal is a real computer. If a command connects to the internet, that connection is yours.

This website

This site sets no cookies and runs no analytics. Fonts are served from this site, not from a third party. The site is hosted on GitHub Pages, and downloads are served from GitHub Releases through a Cloudflare redirect. Those services keep their own standard logs.

If this changes

If Jasiri ever collects diagnostics or usage data, it will be opt-in, it will never include your prompts, files, or keys, and this page will say so before that change ships. An email list for launch news is planned for later. This site does not collect addresses yet. If a list launches, this page will say what is stored and how to leave it.

Children

Jasiri is not designed for children.
