Privacy

Last updated 1 October 2026

The short version: Jasiri has no account, no ads, and no analytics. Your project files stay on your phone. The messages you send the agent go to the AI provider you choose, and nowhere else.

What stays on your phone

  • The Linux system, your project folders, and everything the agent writes.
  • Your AI provider key and any SSH keys you create. Jasiri opts out of Android backups, so they are not copied to the cloud.
  • Uninstalling Jasiri removes all of it.

What goes to your AI provider

When you ask the agent for something, Jasiri sends your message, any attachments, and the output of commands the agent runs to the service you configured (OpenRouter, OpenAI, or another compatible service), using the key you pasted. That provider processes it under its own terms and privacy policy. Pick a provider you trust. We do not operate that service and do not receive a copy.

What Jasiri collects

Nothing about you. There are no accounts, no advertising identifiers, no analytics, and no crash reporting in the current version.

Network requests Jasiri makes

  • Update check. When you open the app, it reads a small public file from this website to learn the latest version. The file is the same for everyone. Like any web request, your IP address is visible to the host (GitHub Pages and Cloudflare) in their ordinary logs.
  • Your AI provider, as described above.
  • Package downloads. When you or the agent install software, Jasiri downloads packages over HTTPS from the package servers for its Linux system.
  • Anything you or the agent run. The terminal is a real computer. If a command connects to the internet, that connection is made by you.

This website

This site sets no cookies and runs no analytics. Fonts are served from this site, not a third party. The site is hosted on GitHub Pages and downloads are served from GitHub Releases through a Cloudflare redirect. Those services keep their own standard logs.

If this changes

If Jasiri ever collects diagnostics or usage data, it will be opt-in, it will never include your prompts, files, or keys, and this page will say so before the change ships. A launch-updates email list is planned. If it launches, this page will explain what is stored and how to unsubscribe.

Children

Jasiri is not designed for children.
